# Voice and Format

Load this reference when authoring or rewriting Topic, Showcase, or presenter copy.

## Voice fingerprint

Write like a smart host teeing up a room discussion in a tight X post: builder-focused, concrete, concise, and lightly opinionated.

Lead with what shipped, leaked, broke, became cheaper, opened weights, or changed policy. Name the cost, speed, risk, locality, control, or comparison that makes it matter.

Useful moves:

- "Useful as an inference-cost story, not just a paper story."
- "A clear signal of reducing OpenAI dependency."
- "The bigger idea is agents that keep their own identity, state, and wallet instead of living inside one hosted chat box."
- "Worth comparing against the other agent-first releases."

Replace press-blurb and generated-summary language with the concrete action. Typical weak openings include "This article discusses," "This is an interesting development," "The company announced a new solution," and "This could have implications." Replace abstract constructions such as "signals a broader shift" or "underscores the growing importance" with the shift itself.

Use one short sentence by default. Add a second only for another source-backed fact. Let a useful number survive; cut the sentence that merely says the Topic is important or worth discussing. Use phrases such as "the real story" and "the main signal" only when they sharpen the claim.

## Titles

Name the hook:

- `Chrome DevTools MCP`
- `Claude Code source leaked via npm sourcemap`
- `Everybody wants an agent story now`
- `OpenAI pauses Stargate UK`
- `Waypoint-1.5 brings real-time AI worlds to everyday GPUs`

A title such as `New Model`, `Major AI News`, or `New Benchmark` is unfinished. Replace it with the model, company, artifact, pattern, or failure.

## Description shapes

- `[Actor] shipped [artifact], with [specific technical or business angle].`
- `[Artifact] changes [cost/speed/risk/locality/control/comparison].`
- `[Several actors] all did [similar thing]. The pattern is [concrete shift].`

Example:

```md
- **mesh-llm pools compute for open models** - Block's Michael Neale is pitching mesh-llm as an OpenAI-compatible inference mesh for pooling spare compute across open models
  Source: https://docs.anarchai.org/
  Repo: https://github.com/michaelneale/mesh-llm
  Post: https://x.com/jack/status/2039736688457507251
```

## Spoken-copy gate

Read the title and description as if introducing the slide live.

The copy is complete when:

- the title names the hook;
- the description says what changed and why this room cares;
- every claim is supported by a linked source;
- the wording sounds natural when spoken once;
- presenter notes contain only facts or demo cues the host cannot infer from the slide;
- Showcase copy directly says what the member will demonstrate.
