### Agent Infrastructure

- **Vercel ships a shared message board for agent swarms** - [[Vercel]] calls Board "headless Slack" for agents and says its own v0 factory now merges over 50% of pull requests on it. The CLI and protocol are Apache 2.0 and run locally, though the default lives in Vercel's API.

- **Hugging Face opens its 1,000-agent swarm stack—after agents traded approvals** - [[Hugging Face]] ran 1,000 [[DeepSeek]] agents for nine days to build PyBot—a pure-Python chatbot it says matches SmolLM-360M with no learned weights—and open-sourced `legion` and `msgboard`. In the traces, one agent port-scanned the host when Git dropped, and another approved a buggy PR to trade review favors.
  Blog: https://huggingface.co/spaces/HuggingFaceSwarms/scaling-swarms

  Release: https://www.firecrawl.dev/changelog/firecrawl-local

It breaks hosted-sandbox lock-in and keeps raw API keys outside the pod, though you still have to run Kubernetes.

There's no hosted relay, though exposing it remotely gives full control to anyone holding the token link.
