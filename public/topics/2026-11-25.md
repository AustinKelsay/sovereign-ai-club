### Agent Infrastructure

- **Vercel ships a shared message board for agent swarms** - [[Vercel]] calls Board "headless Slack" for agents and says its own v0 factory now merges over 50% of pull requests on it. The CLI and protocol are Apache 2.0 and run locally, though the default lives in Vercel's API.
  Blog: https://vercel.com/blog/introducing-vercel-board
  Repo: https://github.com/vercel/board
  Post: https://x.com/rauchg/status/2123237505810178434
  Post: https://x.com/mattpocockuk/status/2124797717834543167

- **Firecrawl Local rebuilds scraping in Rust at 11 MB idle** - Firecrawl packed local scraping, crawling, and an MCP server into one Rust binary it says runs 37x faster than its old self-hosted stack. Two catches in the fine print: the repo is AGPL-3.0, and search still calls Firecrawl Cloud.
  Release: https://www.firecrawl.dev/changelog/firecrawl-local
  Repo: https://github.com/firecrawl/firecrawl
  Post: https://x.com/firecrawl/status/2123096169630912637

- **Energy cuts agent sandbox bills 88% by moving to GKE** - Energy's Emil Ahlbäck moved customer sandboxes off hosted services onto gVisor pods in GCP and open-sourced the Apache 2.0 setup, dropping costs from 16.6¢ to 1.9¢ per sandbox-hour. The savings come from packing mostly idle agents onto shared nodes and snapshotting sleeping containers to storage.
  Repo: https://github.com/comp-work/gke-sandboxes
  Post: https://x.com/emilahlback/status/2123112073517228286

- **Vercel Labs' screen-relay streams desktops to agents at 120 fps** - [[Vercel]] Labs' screen-relay captures a Mac, Linux, or Windows desktop in H.264 and hands agents a local CLI and API to click and type. There's no hosted relay, though exposing it remotely gives full control to anyone holding the token link.
  Source: https://screen-relay.dev/docs
  Repo: https://github.com/vercel-labs/screen-relay
  Post: https://x.com/lahfir/status/2123260406424838357

- **Pirate Face ships a CLI to torrent open models** - Follow-up to September 30: Pirate Face's MIT CLI lets you download, hash-check, and seed [[Open Models|open weights]] straight from a magnet index if [[Hugging Face]] drops them. Pirate Face claims over 30,000 seeders across 37,000 models, though those peer counts are self-reported.
  Source: https://pirateface.co
  Repo: https://github.com/pirateface/pirateface_cli
  Post: https://x.com/thepirateface/status/2122729928177385483

- **Lastbook packs an offline survival library with local LLM chat** - Lastbook bundles offline maps, manuals, video, and a llama.cpp chat sidebar into one MIT desktop app with no accounts or telemetry. Its growth pitch is "point your agent at the repo," which already shows in a flood of drive-by agent PRs.
  Source: https://lastbook.org
