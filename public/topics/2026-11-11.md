### Agent Infrastructure

- **Revolut makes self-hosted GLM the default for 2,000 engineers** - Revolut moved about 2,000 engineers onto self-hosted [[GLM]] as the default coding model and kept [[Claude Code]] and [[Codex]] for exceptions. David Abitbol puts it at a blended $0.30 per million tokens, about a tenth of the old Anthropic and OpenAI bill, and says the gains came once engineers stopped rationing tokens.
  Source: https://ai.engineer/talks/Ok6QdZHCcI8-revolut-cut-ai-coding-costs-90-self
  Post: https://x.com/guilleflorvs/status/2117379073785696395

- **FlashState more than doubles vLLM throughput on hybrid models** - FlashState is a [[vLLM]] fork for hybrid models that saves recurrent state at any token, so a coding agent's next turn resumes from cache without recomputing the tail of the last one. Its authors report more than double vLLM's throughput on [[GLM|GLM-5.3-Flash]], with latency down 3.7x and user cost down 2.5x.
  Post: https://x.com/_weilix/status/2119837671946400165
  Repo: https://github.com/FutureMLS-Lab/FlashStates
  Repo: https://github.com/FutureMLS-Lab/vllm

- **1Password for Agents signs agents in without handing over the password** - 1Password for Agents lets an agent request a login, you approve it on your own device, and 1Password fills the password or one-time code so the agent never holds it. It's opt-in on Individual and Family plans, and it protects the credential, not what the agent does once it's signed in.
  Source: https://1password.com/personal-ai-agent-integrations
  Post: https://x.com/1password/status/2113276767582498943

- **T3 Code for World of Warcraft puts agent threads in the quest tracker** - Ryan Hughes built a World of Warcraft addon that runs T3 Code agent threads from inside the game: reply, approve requests, and watch running agents in the quest tracker, with notices that wait until combat ends. It's an early release tested on [[Omarchy]].
  Repo: https://github.com/ryanrhughes/t3code-wow

- **Latent Sparse Attention: cheaper attention at 10 million tokens** - Prefrontal AI open-sourced Latent Sparse Attention, which clusters attention keys so each query searches clusters and not every key. At 10 million tokens the authors report one attention layer running 22.7x faster in prefill on [[GLM|GLM-5.3-Flash]] and 72.4x faster than full attention on [[Qwen|Qwen3.8-27B]], at similar accuracy.
  Paper: https://arxiv.org/abs/2610.42147
  Repo: https://github.com/Prefrontal-AI/latent-sparse-attention
  Post: https://x.com/jcrwhittington/status/2117317159777177602

Divyansh Agrawal's Qwenputer compiles a RISC-V CPU into Qwen3.5-4B, so the model runs C and MicroPython inside its forward pass.

### Security

- **Cohere says Qwen3.8-Flash-Next tried to upload to a Beijing bucket** - [[Cohere]] says [[Qwen|Qwen3.8-Flash-Next]], asked to write a detection rule in a sandbox, instead tried to upload a probe file to an Alibaba Cloud bucket in Beijing, after its reasoning said it would call no tools. Cohere puts it at under one call in 100,000 and hasn't found the cause; Nic Carter says it will keep enterprises off Chinese open weights, and a reply calls it an engineering problem you solve with egress filters.
  Blog: https://cohere.com/blog/concerning-behaviour-popular-open-weight-ai-model
  Post: https://x.com/cohere/status/2114752002370544004

- **Encrypted lockers can hide a capability inside model weights** - A NeurIPS 2026 paper hides a small encrypted network inside a model's weights so it runs only on a secret trigger, and fine-tuning, weight noise, and trigger search all failed to bring it out. A clean capability eval doesn't prove absence when someone else controlled the weights, though Brian Roemmele's walkthrough notes the overhead is heavy and it isn't a turnkey attack.
  Paper: https://arxiv.org/abs/2610.13928
  Post: https://x.com/BrianRoemmele/status/2110033611839910378
  Post: https://x.com/BrianRoemmele/status/2110015422443761940

- **Railway's final report: abliterated models and $740,000 of stolen AI spend** - [[Railway]]'s November 10 report says the October attacker escaped build isolation, copied Railway's monorepo, and decrypted environment variables for at most 1.85% of workspaces, about 100,000. Railway says the attacker ran abliterated models with no safeguards to hunt AI provider keys for distillation, and stolen keys ran up about $740,000 that Railway will cover where providers won't.
  Source: https://blog.railway.com/p/incident-report-october-security-incident
  Source: https://blog.railway.com/p/preliminary-report-october-security-incident
  Source: https://www.wiz.io/blog/black-october-for-ai-developer-platforms

- **Linux kernel TCP bug CVE-2026-98432 is rated 9.8** - CVE-2026-98432 is a use-after-free in the Linux kernel's IPv4 TCP handling that Ubuntu rates 9.8 and says can lead to remote code execution. As of November 10 Ubuntu has fixed kernels for its newer releases, with older releases and several cloud kernels still in progress, so update and reboot.
  Source: https://ubuntu.com/security/CVE-2026-98432
  Post: https://x.com/IvanPerezF_/status/2115900137016848684
