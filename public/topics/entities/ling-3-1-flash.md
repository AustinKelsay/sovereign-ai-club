# Ling-3.1-flash

Ling-3.1-flash is Ant Group / inclusionAI's successor to [[Ling-3.0-flash]]. The model card describes a hybrid mixture-of-experts with about 560B total parameters and 25B active, under MIT. The card says the context window can reach 1M tokens, while Ant's own docs say the official service currently exposes 256K.
