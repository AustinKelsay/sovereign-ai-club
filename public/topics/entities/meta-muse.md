# Meta Muse

Meta Muse collects Meta's Muse Spark / Muse Image media-model thread, the Muse Code terminal agent, and Muse Glimmer, the 30B Apache-licensed local agent model.

The September 2026 Muse personal-agent product runs in a dedicated cloud VM; it is distinct from the earlier Muse model and coding-agent releases. Its Confidential VM is a future commitment.

September 2026 model updates include Muse Spark 1.3 with a subsequent max-reasoning option, and Muse Voice Transcribe for streaming recognition, diarization and endpointing. These models are distinct from the Muse personal-agent product.

On October 12, 2026, Muse Wonder went on the Meta Model API and Muse Code at $4 per million input tokens and $20 per million output tokens. Muse Wonder Full stayed on the Muse Code Power and Maximum subscriptions. Muse Spark Open, released October 15, remains the open-weight model under the Muse Model License.

Meta released Muse Ember on November 9, 2026, as its smallest and cheapest Muse model for token-heavy agent work, on the Meta Model API and in Muse Code, reported at $0.10 per million input tokens. On November 24, 2026, Harvey and Baseten reported that RL post-training Muse Spark Open with the Tenet recipe pushed it to 30.3% all-pass on Legal Agent Bench (first model past 30%, using 36% fewer output tokens than base at max effort), while Vals AI's misalignment ledger also documented an earlier Muse benchmark episode slowing down NetworkX.
