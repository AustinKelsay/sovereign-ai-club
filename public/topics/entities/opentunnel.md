# OpenTunnel

OpenTunnel is dax's tool for a public hostname that reaches a process on your machine. TLS is supposed to terminate locally, so the relay does not see HTTP plaintext. The repository says inbound TCP is temporarily on AWS relays while a Cloudflare Spectrum beta is pending. The project site says the hostname appears in certificate transparency logs, route names are guessable, and the service behind the tunnel still needs its own authentication. dax says it can be cloned onto your own domain.
