# Hermes Agent

Hermes Agent is Nous Research's agent product surface for skills, model providers, payments, privacy actions, and model-panel routing experiments. On October 15, 2026, Nous Research added an official plugin for REA, the Reverse Engineer Anything MCP server and skill.
