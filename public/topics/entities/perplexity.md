# Perplexity

Perplexity makes Computer, an agent that can work across a Mac's local files and native apps through the Perplexity Mac app. Hybrid Compute, launched September 1, 2026, splits a task between cloud models and a local model on the Mac. On October 20, 2026, Perplexity said Computer can also run fully local: the model, harness, and task execution stay on the Mac, using Qwen 3.6 or PPLX Pro, Perplexity's post-trained Qwen, with 36 GB of memory recommended. Cloud escalation requires user authorization, and local Computer is offered to Pro, Max, and Enterprise subscribers. On October 16, 2026, Perplexity said it had integrated the REA reverse-engineering skill into Computer and offered up to 10,000 credits to try it. Perplexity also publishes Lily, an MIT-licensed Rust and Metal inference server for one 4-bit Qwen3.6-35B-A3B checkpoint. On October 16, 2026, Perplexity posted Decider v1.2 and a 4B flash. Both cards list Apache 2.0, and both say the repository is private and needs a Hugging Face token.
