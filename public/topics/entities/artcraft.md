# ArtCraft

ArtCraft is Brandon Thomas's creative-tools project. On October 3, 2026 he posted that he had vibe-coded open-source Rust replacements for seven Adobe apps. PhotoCraft's README calls itself a clean-room reimplementation of Photoshop, early alpha, under MIT or Apache 2.0, and says it is not yet a daily professional replacement. The Crafting Apps page later lists thirteen Rust apps, including clean-room Word, Excel, and PowerPoint tools. The repos say the apps were written from scratch.
