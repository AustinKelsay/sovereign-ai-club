# Cua

Cua builds computer-use infrastructure for agents. Cua Driver lets an agent operate native desktop apps on macOS, Windows, and Linux, and Lume builds and runs local virtual machines; both are MIT. Cua Spaces, launched as an SDK on October 19, 2026, gives each agent its own desktop on a laptop, a computer you own, your own cloud account, or a sandbox provider, with Claude Code, Codex, and other agents connected over MCP. Spaces is source-available under FSL-1.1-MIT. Cua's docs say its hosted relay terminates TLS and can read proxied sessions unless the opt-in end-to-end mesh, in beta, is on; local and direct Spaces skip the relay.
