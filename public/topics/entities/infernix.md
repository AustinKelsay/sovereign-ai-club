# Infernix

Infernix is Ian R's Apache 2.0 fork of [[NInfer]], created October 8, 2026. The README says it serves Qwen models on one RTX 5090, keeps [[Qwen|Qwen3.8-Flash-Next]]'s experts in system RAM, and reads the n-gram table from NVMe. The same page says most of the README was written with AI and may be incomplete. Its speed tables are the author's. The headline comparison against [[Strata]] does not run the same quant on both engines.
