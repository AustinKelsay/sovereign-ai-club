# Mellum

Mellum is JetBrains' Apache 2.0 coding model. Mellum2, covered on June 10, 2026, is a 12B mixture-of-experts with 2.5B active. Mellum2.1, posted October 8, 2026, keeps that architecture and adds reinforcement learning for repository work. The October 8 blog says GGUF builds are still coming. JetBrains' October 16 post says 140+ tokens a second in local PyCharm.
