# Gufo

Gufo is an MIT inference engine for AMD Strix Halo machines: a Ryzen AI MAX+ 395, a Radeon 8060S, and up to 128 GB of unified memory. The repository was created August 11, 2026. Its model table loads [[Unsloth]] Qwen GGUFs and antirez's DeepSeek V4 Flash GGUF. The published speeds are the project's, and the README says the peaks include repetitive output.
