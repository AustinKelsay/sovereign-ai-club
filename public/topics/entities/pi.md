# Pi

Pi is Earendil's minimal, MIT-licensed agent harness. Pi 1.0, shipped October 1, 2026, adds Codemode, deferred tool loading, and mid-conversation system messages. Pi Durable is a separate experimental package for long-running agent applications, also MIT.
