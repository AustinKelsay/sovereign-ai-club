# Beam

Beam 1.0 is Reflection's Apache 2.0 mixture-of-experts model, released as open weights on October 16, 2026. The model card lists 501B total parameters, 23B active, a 1M-token context window, and BF16, FP8, and NVFP4 checkpoints.
