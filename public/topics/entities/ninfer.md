# NInfer

NInfer is HaoJun Zhang's Apache 2.0 C++/CUDA inference engine for one NVIDIA RTX 5090. The repository was created June 26, 2026. The README says the build rejects every CUDA architecture except `sm_120a`, and that there is no packaged install. Five official artifacts are listed: Qwen3.6-27B, Qwen3.8-27B, and Qwen3.6-35B-A3B, including NVFP4 packs. The intro also says Qwen3.8-Flash-Next is supported. [[Infernix]] is a later fork.
