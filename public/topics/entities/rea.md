# REA

REA, short for Reverse Engineer Anything, is an MIT-licensed MCP server, CLI, and agent skill by morluto and co-author r00tth3w0r1d. It connects Claude Code, Codex, Cursor, Hermes Agent, and other agents to reverse-engineering tools: Ghidra, Hopper, or IDA for native binaries, plus analyzers for Electron and JavaScript apps, .NET assemblies, Android packages, firmware, and websites. Analysis runs locally, but tool results go to the agent's model provider. The repo dates to April 14, 2026, and the rea-agents npm package to July 12, 2026. After Amjad Masad's October 7, 2026 post that all software will soon be "de facto open-source," REA climbed from about 120 GitHub stars on October 3 to about 346,000 on October 20, becoming GitHub's 10th most-starred repo. Nous Research shipped an official Hermes Agent plugin on October 15, Perplexity integrated it into Computer on October 16, and on October 20 REA paired with Scale AI's open AgentEnv to turn apps into RL environments. REA's disclaimer refuses DRM and anti-cheat circumvention, game cheats, and copying proprietary code or assets. In Korben's October 14 hands-on test, REA was faster on three of four tasks but no more capable than Claude Code told to drive Ghidra on its own.
