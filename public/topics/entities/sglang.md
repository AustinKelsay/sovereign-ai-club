# SGLang

SGLang is an open-source model-serving runtime maintained by the SGLang/LMSYS community. Its decision APIs let applications request typed choices and scores from open models rather than parse generated prose; a System One-compatible route supports TypeSafe SDK clients.

The September 30 announcement demonstrates Qwen3.8-27B playing Pokémon and identifies the nightly image as the currently available build, with v0.5.21 planned for October 1. Interface compatibility and normalized label scores do not establish Jev-equivalent calibration.

In November 2026, NEAR AI said an attacker used an unnamed SGLang remote-code-execution bug to run code on one of its inference servers, inside its secure enclave. NEAR AI reported the bug upstream but named no CVE or fixed version.
